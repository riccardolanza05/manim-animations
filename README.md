# Manim Animations

*[English](#english) · [Italiano](#italiano)*

## English

Three short mathematical animations made with [Manim Community](https://www.manim.community/).

| Topic | Code | Video |
|---|---|---|
| Pythagorean theorem | [`code/scene_Pitagora.py`](code/scene_Pitagora.py) | [`videos/TeoremaPitagora.mp4`](videos/TeoremaPitagora.mp4) |
| Strong law of large numbers (running mean of coin tosses) | [`code/scene_LFGN.py`](code/scene_LFGN.py) | [`videos/LeggeForteGrandiNumeri.mp4`](videos/LeggeForteGrandiNumeri.mp4) |
| Taylor expansion of sin(x) | [`code/scene_Taylor.py`](code/scene_Taylor.py) | [`videos/SviluppoTaylor.mp4`](videos/SviluppoTaylor.mp4) |

Render a scene in 4K (requires Manim and a LaTeX distribution):

```bash
manim -qk code/scene_Taylor.py SviluppoTaylor
```
